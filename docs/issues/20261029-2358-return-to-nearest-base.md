## 맥락

- 사용자 관찰(2026-10-29): 깃발이 귀환하거나 패주할 때 근처에 내 기지가 있어도 무조건 출발한 기지로 돌아간다. 가까운 기지로 돌아가게 바꾸고 싶다.
- 원인(코드 확인): `server/src/game/rules.ts`의 `recallTarget` 우선순위가 다음 순서다.
  1. 지정 귀환 기지(`returnBaseTileId`, 회수 명령에서 지정한 경우)
  2. **출발 타일(`originTileId`)이 아직 내 땅이면 그곳**
  3. 내 기지 중 가장 가까운 곳
  4. 수도
  5. 가장 가까운 내 타일
  - 출발 타일을 잃지 않는 한 3번(가까운 기지)까지 내려가지 않는다. 그래서 늘 출발 기지로 돌아간다.
- 호출 경로: `beginReturn`(`server/src/game/flagops.ts:87`)이 회수·IDLE 자동 회수·패주에서 공통으로 쓰인다. `movement.ts:154`가 RETURNING 중 귀환지를 다시 평가한다.
- 수정 방향(안): 2번(출발 타일)을 빼거나 3번 뒤로 내린다. 회수 명령으로 기지를 지정한 경우(1번)는 그대로 둔다.
- 결정 필요
  - 거리 기준: 그래프 거리(`state.graph.distance`, 지금 3번이 쓰는 것) vs 실제 이동 경로(지형·ZOC 반영). 그래프 거리면 산 너머 기지를 고를 수 있다.
  - 이동 중 더 가까운 기지가 생기면(점령 등) 귀환지를 바꿀지. `movement.ts`가 매 틱 재평가하므로 바꾸는 쪽이 자연스럽다.
  - 쿨타임 중인 기지로도 돌아갈 수 있는지(귀환은 출전 쿨타임과 무관해 보이지만 확인 필요).
- 영향: 봇의 회수 판단(`server/src/game/bot.ts`), 클라이언트 귀환 경로 표시(`returnBaseTileId`·`returnTileId` 사용처), 관련 테스트(`recallTarget` 기대값).
