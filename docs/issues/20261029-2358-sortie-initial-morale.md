## 맥락

- 사용자 판단(2026-10-29): 기지에서 기다리다 적이 기지 근처에 오면 출전해 요격하는 플레이가 너무 강하다. 출전 시 사기를 100%가 아니라 N%에서 시작하게 하는 방안을 검토하고 싶다.
- 지금 규칙
  - 새 깃발은 `morale: MORALE_MAX`(1000)로 만들어진다(`server/src/game/state.ts:511`, `makeFlag`).
  - 사기는 전투력 곱이다. 사기 0 → `MORALE_FLOOR`, 1000 → `MORALE_FULL`이고 사이는 선형이다(`shared/src/combatMath.ts:32-35`). 기병은 750~1300으로 폭이 가장 크다.
  - 비전투 중 틱당 `MORALE_RECOVER` 3, 자기 기지 칸 위에서는 `MORALE_RECOVER_BASE` 10 회복한다. 그래서 N%로 시작해도 행군이 길면 회복된다. 기다렸다가 짧게 나가는 요격에만 불리해지는 셈이라 의도와 맞는다.
  - 기지 칸 위 깃발은 사기 하한 `MORALE_BASE_FLOOR` 300이 있다.
- 검토할 것
  - N 값 후보(예: 50%, 60%, 70%)별로 요격전 결과 변화. `20261029-2358-combat-attrition-sim-script` 스크립트로 확인하면 좋다.
  - 병종별 N을 다르게 할지(기병은 사기 폭이 커서 영향이 가장 크다).
  - 원정 공격자도 같은 N에서 출발하므로 공격 측도 약해진다. 공격자는 행군 중 회복하니 결과적으로 차이가 생기는지 측정해야 한다.
  - 대안 비교: 출전 직후 일정 시간 사기 회복 정지, 기지 근처 교전 시 방어 측 사기 감소 가산 등.
  - 클라이언트 표시: 출전 직후 사기 바가 N%로 보이는지(`snapshot.ts`가 `morale`을 보냄), UI 문구 필요 여부.
- 결정 필요: 채택 여부와 N 값, 병종별 차등 여부.
