- 변경 전 = `ff3b295`(= `origin/main`, GDD v5.14). 스크래치 폴더에 `git worktree add` 로 따로 만들고 `npm ci` 후 측정, 끝나고 지움
- 변경 후 = 브랜치 `claude/defend-posture-capture-a2394f` 의 커밋 전 작업 트리
- M 맵 10인, 봇 전용 NORMAL, 시드 1000~1015 (16판). 하드 타임아웃 = 32.0분(9600 tick). 32.0분에 끝난 판을 타임아웃으로 셈
- 스크립트: 저장소 밖 임시 스크립트(스크래치 `dc-measure.mts`, 트리 경로를 받아 동적 import) + 두 트리의 `gauge.ts` 에 임시 훅 두 줄 — `spend()` 끝에 `globalThis.__civSpend`, `applyTilePushes` 의 `setTileOwner` 직전에 `globalThis.__civCap` (측정 후 되돌림)
- 집계 정의
  - 발령 = `flag_issued` 의 `posture`. 깃발-tick = 매 tick `state.flags` 를 태세별로 셈(RETURNING 포함)
  - 태세 전환 = `flag_posture_changed` 수(→공격 / →방어)
  - 점령 칸 = `applyTilePushes` 에서 주인이 바뀐 일반 칸(기지 칸 제외)을 그 깃발의 태세·이전 주인(중립/플레이어)으로 나눔
  - 점령 병력 = `spend()` 로 빠진 병력을 태세·타깃(일반 칸/기지)으로 나눔
  - 방어 깃발 손실 = 방어 태세 깃발의 패주(`flag_routed`) 또는 `flag_ended` reason `exhausted`·`attrited` (깃발당 1회). "병력 적음" = 그 깃발이 교전에 들어간 시점 병력 ≤ 60명. "점령 직후" = 마지막 방어 점령 지출 후 150 tick(30초) 안

## 해석

- 판 길이는 그대로다(평균 31.1분, 대역 밖 0판, 타임아웃 9→8). 탈락은 2.38→1.81, 플레이어 기지 점령 12.6→10.5로 줄었다. 16판이라 잡음 폭 안일 수 있으나, 방어 주둔 점령이 상대 국경을 조금씩 갉아 먹는 대신 공성 쪽 압력이 늘지는 않았다.
- 봇은 태세를 고르는 기준이 그대로라(내 땅 = 방어, 적·중립 = 공격) 방어 발령 비율(18.7→17.6%)과 방어 깃발-tick 비율(49→50%)이 거의 같다. 바뀐 것은 국경 주둔 방어 깃발이 저절로 옆 칸을 먹는 것뿐이고, 방어 깃발-tick 중 실제로 점령한 tick 은 1.5%에 그친다(옆 칸이 대부분 비었거나 교전 중).
- 방어 점령은 판당 약 726칸(전체의 5.6%, 적 땅 점령의 9.1%)이고 병력은 판당 약 17,000명(점령 지출의 7%)을 썼다. 공격 태세가 먹는 칸 수는 줄지 않았다.
- '→공격' 태세 전환이 판당 25.9→10.7로 줄었다. 봇이 주둔 깃발을 반격용 공격으로 돌리던 일 일부를 방어 주둔 점령이 대신한다.
- 교전 시작 때 병력이 60명 이하였던 방어 깃발 손실이 판당 5.9→9.9(+4)로 늘었다. 방어 깃발 손실 전체는 54→57로 +3 정도라, 점령으로 40명 근처까지 줄어든 깃발이 맞고 지는 일이 늘었지만 규모는 작다. 손실 방어 깃발의 41%(23.4/57.3)는 마지막 방어 점령 후 30초 안에 졌다.
