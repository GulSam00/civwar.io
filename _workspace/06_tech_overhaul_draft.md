# 테크 개편 설계 초안 (rev.1, 2026-10-24)

사용자 요청(2026-10-24): ① 4테크로 확장 ② 전반 기술 조정 ③ 병종 개성 강화 ④ 내정 개편은 **제안** ⑤ 군사 병종 수치를 비율이 아니라 10·20·30 같은 **절대값**으로.
원칙: **밸런스는 계산하지 않는다.** 모든 수치는 [A] 자리표시이고, 한 표에 모아 추후 일괄 패치한다. 전투 모델 2 적용(사기 노드 포함)은 이 개편과 함께 한다.

> 이 문서는 제안이다. 결정 전에는 코드를 바꾸지 않는다. 결정 질문은 §8.

## 1. 기술 제약 — 32노드 상한 (프로토콜 변경 필요)

- 현재 보유 노드는 `techMask` **uint32 비트마스크**라 노드가 **32개를 넘을 수 없다**(`TECH_NODE_COUNT = 32`, 검사 코드 `validateTechNodes`).
- 7갈래 × T1~T4를 (1·2·2·1) 모양으로 하면 갈래당 6노드 → **42노드**. 마스크를 넘는다.
- 영향 범위: `techMask`가 서버·클라이언트·테스트 32개 파일, 약 53곳(스냅숏·델타·`player_tech`, 봇, 테크 창).
- 해법 후보
  - **A. 마스크를 두 단어로**(`techMask` = 하위 32비트 + `techMaskHi` = 상위 32비트, 최대 64노드). 기존 필드를 유지해 호환이 쉽다. **추천.**
  - B. 노드 id 배열로 전송(모양이 바뀌어 수정 범위가 큼).
  - C. 노드를 32개로 유지(4티어 대신 갈래당 4~5노드) — 4티어의 의미가 줄어든다.

## 2. 절대값 전환 (병종 수치)

지금 식(모델 1): `전투값(‰) = 병종 기본(‰) × 테크 배율(‰) / 1000`, 테크 배율 = 1000 + Σ(공통 + 병종별 증분 ‰).

제안: **점수(point)** 단위. 병종 기본을 점수로 다시 적고(‰ ÷ 10), 테크는 점수를 더한다.

| | 창 | 검 | 기병 |
|---|---|---|---|
| 공격 기본 | 87 | 100 | 118 |
| 방어 기본 | 130 | 100 | 70 |
| 이동 기본 | 75 | 100 | 145 |

- 식: `전투값(점수) = 병종 기본 + Σ 테크 점수`, 내부 계산은 ×10 해서 ‰와 같은 정밀도를 쓴다.
- 테크 폭 [A]: T1 +10, T2 +10 ~ +20, T3 +20, T4 +30. 공통(군사 갈래)과 병종 갈래가 같은 점수 단위를 쓴다.
- 적용 대상: **ATK·DEF·이동 속도**(병종 능력치). 점령비용·유지비·편성비·골드·병력 상한 같은 경제·내정 수치는 비율을 그대로 둔다(제안).
- 효과가 달라지는 점(결정 참고): 같은 +10이 **기본값이 낮은 쪽에 더 크게** 작용한다(기병 방어 70 → +14%, 창병 방어 130 → +7.7%). 약점 보완과 강점 강화 중 노드가 어느 쪽인지로 병종 개성을 설계할 수 있다.
- 클라이언트: 부대 정보 창의 "기본 · 테크" 표시가 점수 합으로 바뀐다. 모델 2의 채널 값(`channelValues`)은 기본 점수에 테크 점수를 더하도록 바꾼다.

## 4. 병종 개성 (확정: 수치만, 새 엔진 효과 없음)

병종 갈래마다 **서로 다른 수치 축**으로 정체성을 가른다. 같은 +10이라도 기본 능력치가 다르므로 효과가 다르다.

| | 창병 — 수비·유지 | 검병 — 균형·돌격 | 기병 — 기동·기세 |
|---|---|---|---|
| 정체성 | 오래 버티는 방어선(방어 점수, 낮은 유지비, 사기 지속) | 공방 균형 + 싼 점령 | 빠른 단기 돌파(속도, 공격, 기세) |
| T1 | 장창 대열: DEF +10 | 검술: ATK +10 | 군마: 이동 +10 |
| T2A | 주둔 진지: 유지비 가중치 0.60 → 0.45 | 사슬 갑옷: DEF +10 | 마구간: 편성비 1.15 → 1.07 |
| T2B | 방진: DEF +10 | 돌격 보병: 점령비용 ×0.95 | 기병창: ATK +10 |
| T3A | 고슴도치 진(방진 후): DEF +20 | 철갑 보병(사슬 후): DEF +20 | 역참(마구간 후): 유지비 가중치 1.60 → 1.30 |
| T3B | 버티는 대열(주둔 후): 사기 감소 −25% | 정예 보병(돌격 후): ATK +20 | **돌격 기세**(기병창 후): 사기 만땅 기세 +5%p |
| T4 | 철벽: DEF +30 | 백전노장: ATK +30 | **철기**: 사기 감소 −30% |

- 사기 노드(굵게 포함): 창 T3B, 기병 T3B·T4. 공통 사기는 군사 T4(군기)·기동 T4(야영 정비).
- 기병의 단기 돌파는 돌격 기세로, 대신 사기 소모가 가장 빠른 구조는 그대로 둔다.

## 6. 내정 개편 제안 (요청 사항 — 경제 ECO·영토 TER)

현재는 골드 +8·10·12%, 유지비 −20%, 병력 재생 +6%, 중립 점령비용 −6·−8%, 병력 상한 +6·+8%, 보급선 −25% 등 **수치 막대 위주**라 갈래를 고르는 이유가 약하다. 세 안을 낸다.

### 안 1 — 수치 정리 + 분기 선택화 (변화 작음)
- 구조·효과를 그대로 두고 T4 노드만 추가. 2A/2B는 지금처럼 둘 다 살 수 있다.
- T4 예: 경제 = 전시 경제(출전 깃발 수가 많을수록 골드 보너스), 영토 = 수도 승격(수도 생산 +).
- 장점: 작업이 작다. 단점: 개성이 늘지 않는다.

### 안 2 — 재정·행정으로 역할 분리 (추천)
- **재정**(경제): 골드·유지비·병력 재생의 순환. **행정**(영토): 확장과 기지.
- 2A/2B를 **양자택일(상호 배타)** 로 만들어 갈래마다 두 가지 길이 있게 한다.

| 티어 | 재정 FIN | 행정 ADM |
|---|---|---|
| T1 | 세금 징수: 골드 +8% | 개척민: 중립 점령비용 −6% |
| T2A (택일) | 상업: 골드 +10% | 확장: 중립 점령비용 −8% |
| T2B (택일) | 군수: 깃발 유지비 −20% | 요새화: 기지 체력 +20% |
| T3A | 조폐국: 골드 +12% | 도로망: 보급선 비용 −25% |
| T3B | 곡창: 병력 재생 +8% | 기지 재건: 기지 생산력 회복 속도 +50% (함락 후 약 3분 → 2분) |
| T4 | **전시 경제**: 출전 깃발마다 골드 +2% (상한 +10%) | **수도 승격**: 수도 생산 +30%, 수도 기지 체력 피해 상한 −20% |

- 기지가 이 게임의 멸망 조건이라, **행정에 기지 방어·회복 노드를 넣어 약소국 방어 돌파 문제의 한 축**을 둔다.
- 지형 경제는 건드리지 않는다(사용자 결정 유지). 위 노드에는 지형별 골드 효과가 없다.

### 안 3 — 내정 단일 갈래 통합 (변화 큼)
- 경제와 영토를 **하나의 큰 "내정" 갈래(2줄 × 4티어)** 로 합친다. 갈래 수 7 → 6, 총 노드 약 36개로 줄어 마스크 확장이 필요 없을 수도 있다.
- 장점: 갈래가 단순해진다. 단점: 한 갈래 안에서 골드와 확장 중 고르는 부담이 커지고, 지금 UI(7열 격자)를 고쳐야 한다.

## 10. 결정 기록과 확정 노드 표 (2026-10-24)

사용자 답: **Q1 4티어 / Q2 마스크 확장 허용 / Q3 수치만(새 효과 없음) / Q5 내정 안 2(재정·행정)**. Q4(절대값 범위)는 제안대로 ATK·DEF·이동만, 점수 폭은 [A].

- **마스크 확장 방식 변경(구현 중 발견한 더 작은 해법)**: 두 단어(`techMaskHi`) 대신 **`techMask`를 하나의 53비트 안전 정수**로 쓴다. 필드·프로토콜 모양이 그대로이고(JSON 정수 ≤ 2^53), 비트 연산을 쓰던 곳이 약 6곳뿐이라 고치기 쉽다. 노드는 최대 53개. 42노드는 들어간다.
- 2A/2B 양자택일은 **재정·행정만** 적용, T4는 T3A **또는** T3B 중 하나를 보유하면 열린다(`parentAlt`).
- 기지 효과는 최대치를 바꾸지 않고 **피해 감소 / 생산력 회복 속도 / 수도 생산**으로 구현한다(`BASE_DMG`·`BASE_RECOVER`·`CAPITAL_PROD` 스탯 칸 추가, TECH_STAT_COUNT 44 → 47).
- 병력 상한(`TROOP_CAP`) 노드는 이번에 뺀다(곡창의 병력 재생과 겹침). 전시 경제는 새 효과라 빼고 T4를 골드 +15% 수치로 둔다.
- 점수 단위: 병종 전투값 = `UNIT_ATK/DEF_PERMILLE[unit] + 10 × (공통 점수 + 병종 점수)`, 이동도 같은 형태. 점령비용·유지비·편성비·골드 등은 비율 유지.
