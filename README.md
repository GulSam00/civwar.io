# civwar.io

실시간 멀티플레이어 영토 정복 IO 게임. 2~12인, 한 판 25~32분(표준 30분).

깃발에 병력을 실어 보내 땅을 점령하고, 공격/방어 태세로 적 깃발과 싸운다. 점유율이 승리 기준(16분부터 60% → 26분에 45%)에 닿거나 32분 하드 타임아웃 시 점유율 1위가 승리한다.

규칙 요약 (v4.5):
- 물(맵의 약 10% — 테두리 바다·안쪽 호수)은 지나갈 수 없다. 육지는 한 덩어리로 이어져 있다.
- 중립 땅 점령 비용은 칸당 고정(나라 크기와 무관). 남의 땅 위 깃발은 병력이 조금씩 줄어든다(적 땅 분당 약 14%, 중립 절반).
- 깃발 전투 손실은 0.2초마다 약 0.9% — 깃발 위에 `−n` 숫자로 보인다. 자기 기지 칸 위 깃발은 태세와 무관하게 ×1.5.
- 기지가 받는 체력 피해는 깃발 수와 무관하게 상한이 있다(가득 찬 기지도 최소 15초).
- 생산 = 영토(내 땅 전부) + 기지(기지 60칸분, 수도 100칸분 × 생산력). 기지는 함락될 때마다 생산력 절반, 약 3분에 걸쳐 회복. 기지를 모두 잃으면 멸망·합병.
- 방어 태세 깃발은 적 땅을 지나가지 못한다(막히면 적 땅 앞에서 멈춤). 지명은 서양식 판타지 지명(한국어 음차).

## 실행

요구: Node.js 22, npm.

```bash
npm install
npm run dev
```

서버(ws, 8080)와 클라이언트(Vite, 5173)가 함께 뜬다. 브라우저에서 http://localhost:5173 접속 → 닉네임 → **빠른 시작**. 빈자리는 봇이 채운다.

따로 띄우기: `npm run start:server`, `npm run dev:client`. 다른 서버에 붙이기: `http://localhost:5173/?ws=ws://<host>:8080`.

## 조작 (PC)

| 입력 | 동작 |
|---|---|
| 맵 지점 클릭 → 삼각형 메뉴(클릭 또는 `1`/`2`/`3`) | 가장 가까운 내 기지에서 창병(창 아이콘) / 검병(검 아이콘) / 기병(말굽 아이콘) 출전 (내 땅 = 방어, 적·중립 = 공격 태세). 맵 깃발 표식에도 같은 아이콘 |
| 내 기지 클릭 → 지점 클릭 → 메뉴 | 그 기지에서 출전 |
| 하단 바 / `Q` / `E` | 보낼 병력 비율 (초당 골드 수입·유지비 표시) |
| 깃발 클릭 / 병력 바 위 부대 칩 | 선택 (내·적·동맹 모두 — 우측 패널에 공격력·방어력). 칩은 카메라도 그 부대로 |
| 내 부대 선택 → 우클릭 | 그곳으로 이동 (내 땅·기지 = 방어, 적·중립 = 공격 — 태세 자동, 쿨타임·전투 중이면 "태세 전환 대기") |
| 선택 부대 옆 `귀환` / `태세 변경` 버튼, `R` / `F` / `Tab` | 가까운 내 기지로 귀환(취소 불가, 귀환 속도 ×1.5 — 「급속 귀환」 ×2.2) / 태세 전환(쿨타임 5초) / 내 깃발 순환 |
| 창 제목 줄 드래그 | 테크·외교·옵션·도움말 창 옮기기 (위치 기억) |
| HUD 병력·골드 hover | 출처: 기지별(지명·생산력) + 영토 |
| 마우스 hover | 지형 정보 툴팁(유형·방어·이동 속도·점령 비용·골드·소유자·기지 지명·체력·생산력, 한 줄에 한 항목 — 옵션에서 항목별로 끄고 켬) |
| 게임 종료 후 `맵 보기` | 최종 맵 둘러보기, 점수판 이름 클릭으로 플레이어 따라가기 |
| HUD 톱니 버튼 / `O` | 옵션 창: 색각 보조, 깃발 이동 방향 화살표(모두 / 내 깃발만 / 숨김), 지형 툴팁 켜기·항목 선택 (브라우저에 저장, `Esc`·바깥 클릭으로 닫기) |
| HUD `테크` 버튼 / `T` | 테크 창(갈래 7열 × 티어 3줄 격자, 버튼 숫자 = 지금 살 수 있는 노드 수). 노드 클릭 → 상세(효과 지금 → 구매 후, 가격, 선행, 대기 시간) → `구매` 버튼. `Esc`(상세 → 창)·바깥 클릭으로 닫기. 관전·종료 후에는 보기 전용, 좁은 화면은 갈래 탭 |
| `P` / `C` / `V` / `?` | 외교 / 색각 보조 / 이동 방향 화살표 순환(모두 → 내 것만 → 숨김) / 도움말 |

## 개발

| 명령 | 내용 |
|---|---|
| `npm run typecheck` | shared·server·client 타입 검사 |
| `npm test` | 전체 테스트 (vitest) |
| `npm run smoke` | 실제 ws 서버 스모크 |
| `npm run build:client` | 클라이언트 빌드 |
| `npm run selfplay -w @civwar/server -- 10 1000 M 10` | 봇 자가대전 (판 수, 시드, 크기, 인원) |
| `npx tsx server/scripts/export-map.ts --size M --seed 1000 --count 40` | 맵 후보 생성 → `node server/scripts/eval-maps.cjs server/maps/candidates` 로 평가 |

## 구조

- `shared/` 상수(밸런스 단일 소스)·프로토콜 타입 — 서버·클라이언트가 TS 소스를 그대로 공유
- `server/` 권위 서버: 5Hz 결정론 tick, 맵 생성·공식 맵 9장(`server/maps/official`), 봇 AI
- `client/` React + Canvas 클라이언트
- `_workspace/` 설계·프로토콜·QA 문서 — GDD `01_game-designer_gdd.md`, 프로토콜 `02_backend_protocol.md`(클라이언트의 신뢰 소스), 결정 기록 `00_input/design-decisions.md`
